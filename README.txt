# Deepu Love App ❤️

## Folder structure

Deepu-Love-App/
├── index.html
├── style.css
├── script.js
├── images/
│   ├── memory1.jpg
│   ├── memory2.jpg
│   ├── memory3.jpg
│   └── memory4.jpg
└── music/
    └── our-song.mp3

## Customize

Open `script.js`.

At the top you can edit:
- questions
- yes/no responses
- memory titles and captions
- secret message

Add your own photos into `images/`.
Add your song as `music/our-song.mp3`.

Then open `index.html` in Chrome.

## Put it online

Easy options:
1. GitHub Pages
2. Netlify
3. Vercel

For a simple static website, all three can host these files without a backend.
